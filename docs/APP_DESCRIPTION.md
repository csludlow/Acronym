# App description

## Short description

A guided workspace for preparing vendor security questionnaires and accessibility reports.

## Full description

Acronym helps small software vendors prepare security questionnaires and accessibility reports for college and university purchasers. It explains unfamiliar questions, organizes evidence and testing results, and guides users through human review. Users leave with an editable preparation package and clear next steps for completing the requested HECVAT and VPAT-based documents.

## What users can do

- Get started with plain-language questions and a guided product profile.
- Connect responses to documents, testing results, and human attestations.
- Record accessibility findings and limitations for the product being assessed.
- Review responses, resolve missing information, and track changes.
- Download a preparation package and follow clear steps to finish and submit the purchaser’s requested documents.

Acronym is an unofficial preparation guide. The user completes the requested questionnaire and report, verifies accuracy and coverage, and approves the final submission. The current prototype runs locally with external AI processing disabled.
